## 📌 About the Project

PhishAware is a web-based phishing awareness and cybersecurity education platform designed to help users understand phishing attacks, recognize suspicious messages, and improve their online security awareness.

The project provides an interactive learning experience to help users identify common phishing techniques and stay safer online.

## ✨ Features

- 🔐 User authentication using Firebase
- 📧 Email and password registration and login
- 🔑 Password reset functionality
- 🛡️ Phishing awareness and educational content
- 📚 Interactive cybersecurity learning
- ☁️ Firebase integration
- 🌐 Responsive web interface

## 🚀 Getting Started

### Prerequisites

- Visual Studio Code
- Google Chrome or another modern browser
- Node.js (if required by your project setup)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/abhishek-suresh-jyothi/CodeAlpha_PhishAware.git
   ```

2. Open the project folder in Visual Studio Code.

3. Configure Firebase by creating a Firebase project in the Firebase Console.

4. Add your Firebase web configuration to the appropriate configuration file.

5. Run the project using Live Server or your configured development environment.

## 🔥 Firebase Setup

This project uses Firebase services for authentication and database functionality.

To configure Firebase:

1. Create a project in the Firebase Console.
2. Register a web application.
3. Enable Firebase Authentication.
4. Configure Firestore if required.
5. Add the Firebase configuration to your project.
